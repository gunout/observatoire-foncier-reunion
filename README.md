# 🏛️ Observatoire Foncier — La Réunion

**Analyse du potentiel foncier et de la crise du logement à La Réunion.**

24 communes · 5 modules · Sources : INSEE RP 2023, ARMOS OI / RPLS 2026, Notaires 2026.

## Modules

| Module | Contenu |
|--------|---------|
| Vue d'ensemble | Carte + stats + tableau triable |
| Marché & Foncier | Construction, loyers, vacance, friches |
| Société | Démographie, ménages, emploi |
| Économie & Emploi | Mobilités, secteurs d'activité |
| Risques & Environnement | Cyclones, contraintes, énergies |

## Sources officielles

- **Population** : INSEE RP 2023 (décret 26/12/2025)
- **Parc social** : ARMOS OI / RPLS 01/01/2026
- **Prix immobilier** : Notaires / Figaro Immobilier avril 2026
- **Chômage** : INSEE T2 2025 (départemental)
- **Risques** : BRGM, DEAL

## Installation

    git clone https://github.com/gunout/observatoire-foncier-reunion.git
    cd observatoire-foncier-reunion
    npm install
    npm run dev

## Build

    npm run build

## Déploiement

Automatique à chaque `git push` sur `main` via GitHub Actions.
